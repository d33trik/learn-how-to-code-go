# Learn How To Code: Go

This repository contains my exercises created while following the course _["Learn How To Code: Google's Go (golang) Programming Language"](https://www.udemy.com/course/learn-how-to-code/)_ by [Todd McLeod](https://www.linkedin.com/in/tamcleod).

The goal of this repository is to practice Go fundamentals, track my progress, and keep all exercises organized in a single place.
